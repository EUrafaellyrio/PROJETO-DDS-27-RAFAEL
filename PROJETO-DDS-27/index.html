Sobre o sistema

O trocAqui é uma plataforma web de escambo. Ofertantes cadastram produtos, interessados demonstram interesse e o ofertante recebe o contato de quem se interessou. O sistema usa Node.js, Express, EJS e MySQL, com três perfis: administrador, ofertante e interessado.

Projeto: GitHub | Documentação: Google Docs
